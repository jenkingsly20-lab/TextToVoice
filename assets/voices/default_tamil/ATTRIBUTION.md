# Tamil default reference voice

Source: [AI4Bharat Rasa](https://huggingface.co/datasets/ai4bharat/Rasa), Tamil test split, sample **TAM_F_BOOK_00014**, female book-narration style. Exact transcript is supplied by that same dataset row in `transcript.txt`; it was not inferred or rewritten. Dataset revision and audio SHA-256 are recorded in `voice.json`.

Credit: Praveen Srinivasa Varadhan, Ashwin Sankar, Giri Raju and Mitesh M. Khapra / AI4Bharat, *Rasa: Building Expressive Speech Synthesis Systems for Indian Languages in Low-resource Settings*, INTERSPEECH 2024.
